# Voice Notes — The Voynich Manuscript

**Provenance:** `assets/audio/final_voice.mp3` is a real, already-recorded
narration provided directly for this project — `voice_script.txt` is authored
to match its subject/structure/duration, not verified as its literal
transcript.

## Simplifications for read-aloud clarity

- "Beinecke MS 408" → "Beinecke M-S four-oh-eight" (letter-by-letter + digit
  read-out, avoids an awkward acronym stumble).
- "2011" → "twenty-eleven", "1404-1438" → "fourteen-oh-four and fourteen
  thirty-eight", "1940s" → "nineteen-forties" — spelled phonetically so the
  narrator doesn't default to a flat digit-by-digit read.
- "Purple cipher" kept as-is — it's the historically correct name (Imperial
  Japan's WWII diplomatic cipher), not a typo.

## Pause markers

- Ellipses (`...`) mark dramatic beats/breath points, mirroring the mid-clause
  pauses in `script.md` (e.g. "Not because it's written in a lost language...
  but because...").
- Paragraph breaks correspond to `script.md`'s section boundaries — natural
  places for a breath or a very slight pace reset, not necessarily a hard
  stop.

## Pacing note

This script's total word count (770) implies a slower-than-typical narration
pace (~70 words/min) against the real 656-second runtime — consistent with a
deliberate, moody documentary delivery with room for pauses, not a rushed
read. If the actual recording reads noticeably faster or slower than this
script's beats suggest, that's expected given the provenance note above.
