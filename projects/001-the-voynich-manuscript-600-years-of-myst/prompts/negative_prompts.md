# Negative Prompts — The Voynich Manuscript

Common across all scenes: saturated colors, cartoon/flat-illustration
rendering, modern anachronistic objects (except the narratively-justified
1940s cipher machine in scene_009 and modern scanning instrument in
scene_012), clean/new-looking paper where aged parchment is expected,
direct-to-camera character close-ups.

See `visual_prompts.json` for each scene's exact `negative_prompt` string.
